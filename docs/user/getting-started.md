# 快速开始

## 安装

从 [GitHub Releases](https://github.com/wuxinzhe/tinkerdesk/releases) 下载最新安装包（`TinkerDesk Setup X.Y.Z.exe`）——双击安装。应用会自动检查更新（后台下载新版本）。

不需要安装任何其他东西（Node.js 不需要——应用自带运行环境）。

## 首次启动（4 步初始化）

```
① 创建默认 Agent（你的 AI 助手——角色设定）
② 配置模型（API Key）
③ 完成——进入聊天
```

第 ② 步：选择模型供应商 → 填 API Key → 应用会拉取可用模型列表 → 绑定主聊天场景。

## 开始聊天

```
- 左下输入框打字 → 回车发送（或 Ctrl+B 按住说话——语音输入）
- Agent 回复流式显示——可以随时打断/追问
- 干活型任务：让 Agent 用工具（终端/文件/搜索/网页）帮你完成——
  危险操作会弹审批卡片（你确认才执行）
```

## 配置你的 Agent

- **角色设定**（Agent 设置）：告诉 Agent 它是谁、怎么说话（灵魂提示词）
- **模型**：切换模型 / 绑定场景（对话用哪个、标题用哪个）
- **技能**：给 Agent 添加能力包（技能 = 可复用的知识/流程）
- **插件**：语音、工具增强（音色克隆、本地识别等）

## 常见入口

```
左侧边栏：会话列表 / Agent 管理 / 设置
聊天页：右上工具栏（清空/统计/设置抽屉）
设置：快捷键 / 主题 / 通用
```
