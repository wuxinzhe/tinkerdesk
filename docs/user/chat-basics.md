# 聊天基础

## 发送消息

- 打字：输入框回车发送
- 语音：**Ctrl+B 按住说话**（松开发送）——STT 转文字后发送（需要语音插件/引擎）
- 中断：Agent 回复时按 Esc / 打断按钮——停止当前回复

## Agent 忙碌时的行为（三模式）

Agent 正在干活（工具执行/长回复）时你发新消息：

| 模式 | 行为 |
|:--|:--|
| 排队（默认） | 新消息入队——当前任务跑完再处理你的消息 |
| 重定向 | 立即修正当前任务方向（Agent 会重新理解你的意图继续） |
| 打断 | 停止当前任务——立即处理你的新消息 |

模式在 Agent 设置里配置（messageBusyMode）。

## 审批（危险操作）

Agent 执行危险操作（删文件/改系统/跑高危命令）时——弹**审批卡片**：

```
[工具] terminal 要执行：rm -rf C:\xxx
[同意] [拒绝] [自动同意（本次对话）]
```

- 拒绝 → Agent 收到拒绝原因，换方案
- 自动同意 → 本对话内同类操作不再询问
- 审批 5 分钟无响应自动拒绝

## 工具调用可视化

Agent 用工具时显示工具卡片（工具名/参数/结果）——执行过程透明可见（不黑盒）。

## 附件

- 发送图片/音频/视频：消息框附件按钮 → 选择文件 → 自动拷贝到应用媒体目录 → 以消息形式发送
- Agent 可以看到/听到附件内容（多模态模型/语音工具）

## 会话管理

- 左侧会话列表：历史会话（自动生成标题——可搜索）
- 新会话：+ 新建
- 撤回：撤销自己刚发的消息
- 清空：清除当前会话记录
