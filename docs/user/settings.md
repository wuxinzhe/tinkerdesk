# 设置

## 通用设置（app_settings）

| 设置 | 默认 | 说明 |
|:--|:--|:--|
| 主题 | light | light / dark / system |
| 录音快捷键 | Ctrl+B | 按住说话 |
| 事件埋点 | 开 | agent_events 表（执行追溯——诊断用） |
| 事件上限 | 50000 | 环形清理（超了自动删最旧） |

## Agent 设置（每个 Agent 独立）

```
角色设定    灵魂提示词（Agent 怎么说话/做什么）
运行参数    最大迭代轮数 / 忙碌模式 / 压缩阈值等（per-agent）
模型绑定    各场景用哪个模型（主模型 + 备用回退）
```

## 模型管理

```
- 接入模型：供应商/API Key/模型名/上下文长度/API 模式
- 场景绑定：聊天 / 标题生成 / 摘要 各用哪个模型
- 拉取模型列表：填 Base URL + Key → 自动拉取可用模型
```

## 工具管理（L3 设置页）

```
- 工具清单：内置工具（终端/文件/搜索/网页/语音...）+ 可用状态
- 禁用工具：黑名单（禁用后 Agent 不再调用）
- provider 选择：语音（TTS/STT）、搜索、抓取——插件 provider vs 内置实现
- MCP 服务器：添加外部 MCP 服务器（标准协议接入更多工具）
```

## 技能管理

```
- 技能列表：已安装技能（详情/文件/编辑）
- 导入技能：从 zip / 目录导入
- 技能分类
```

## 插件管理

```
- 插件列表：manifest + 状态（启用/停用）
- 插件配置：动态表单（secret 字段脱敏显示）
- 安装：zip / 目录（npm 依赖自动装）
```

## 快捷键

| 快捷键 | 动作 |
|:--|:--|
| Ctrl+B | 按住录音（语音输入） |
